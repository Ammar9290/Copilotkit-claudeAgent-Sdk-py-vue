# Generative UI

CopilotKit supports multiple approaches to generative UI:

- [Display Only](/generative-ui/display) — Agent renders read-only components
- [Interactive](/generative-ui/interactive) — Agent renders interactive components with callbacks
- [Tool Rendering](/vue/claude-sdk-python/generative-ui/tool-rendering) — Map backend tool calls to UI components
- [State Rendering](/vue/claude-sdk-python/generative-ui/state-rendering) — Render UI from agent state
- [MCP Apps](/vue/claude-sdk-python/generative-ui/mcp-apps) — Model Context Protocol integrations
- [Components and surfaces](/vue/claude-sdk-python/generative-ui/components): the agent renders your React components, in the chat and in areas of your page
- [A2UI](/vue/claude-sdk-python/generative-ui/a2ui) — Agent-to-UI protocol
- [Your Components](/vue/claude-sdk-python/generative-ui/your-components) — Use your own component library
